#BASIC CYBERSECURITY CHECKLIST
##Daily Checklist
- Verify email sender before clicking
- Lock computer when leaving desk
- Report suspicious emails to IT

##Weekly Checks
- Update or patch systems
- Change passwords if there is suspicious activity
- Backup critical information or files
- Review login history

##If Phishing Happens
- Disconnect internet
- Change password immediately
- Report incident within said number of days
