# phishing-awareness-resource
simple guide to help users identity and report phishing attacks

##Project Overveiw
This repository is a mini cybersecurity project for partc. It focues on phishing awareness which more commonly used as a cyber threat globally

##Contents Of Repository
-Phishing Guide-Full guide on how to spot and avoid phishing attacks
-Basic Checklist-Weekly and daily cybersecurity checklist
-Incident Report Template-A template for reporting phishing incidents

## Purpose
The objective of this miini project is to help junior employees, staff members and students comprehend
1. What phishing is
2. How to spot phishing emails or texts
3. What to do when received 
4. How to report incidents properly

## How to navigate
1. Start first by reading phishing guide.md
2. Utilize basci-checklist.md daily before opening any emails
3. If a suspicious email is received, use the incident-report-template.md on how to repot step by step

SOC team members, general staff and junior cybersecurity analysts
